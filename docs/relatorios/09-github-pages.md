# Parte 9 — Publicação no GitHub Pages

## 1. Objetivo

Publicar o DevStudy Hub na internet utilizando o GitHub Pages.

## 2. Procedimentos

Configuramos o GitHub Pages para publicar o conteúdo da pasta `docs` da branch `main`.

Após a publicação, testamos a página e a interação das categorias de estudo.

Criamos a Issue #13 para adicionar os links dos Relatórios 3 a 8. Desenvolvemos a melhoria em uma branch separada e realizamos o merge pela Pull Request #14.

## 3. Resultado

O site foi publicado, atualizado e validado com sucesso.

[DevStudy Hub — Site publicado](https://mateusvsaraujo2-slyter.github.io/devstudy-hub/)

## 4. Aprendizados

Aprendemos a publicar um site pelo GitHub Pages e a atualizar sua versão pública utilizando Issues, branches, commits e Pull Requests.
