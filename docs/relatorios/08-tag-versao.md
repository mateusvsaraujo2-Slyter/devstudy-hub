# Parte 8 — Tag de versão

## 1. Objetivo

Identificar a primeira versão funcional do DevStudy Hub utilizando uma tag Git.

## 2. Procedimentos

Atualizamos e validamos a branch `main`, verificando o estado do repositório e o histórico de commits.

Criamos a tag anotada `v1.0.0` e publicamos no GitHub utilizando `git push origin v1.0.0`.

## 3. Resultado

A tag foi publicada com sucesso e identifica o commit `078c5c2` do projeto.

## 4. Aprendizados

Aprendemos que uma tag identifica um ponto específico do histórico Git, permitindo marcar versões do projeto sem acompanhar automaticamente novos commits, como acontece com as branches.
