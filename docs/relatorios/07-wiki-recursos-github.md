# Parte 7 — Wiki e recursos do GitHub

## 1. Objetivo

Conhecer os recursos do GitHub utilizados para organizar e documentar o DevStudy Hub.

## 2. Procedimentos

Criamos três páginas na Wiki: visão geral, fluxo Git e convenções de branches e commits.

Revisamos as configurações do repositório, incluindo a branch principal, Issues, Wiki, Projects e opções de merge, sem realizar alterações desnecessárias.

Também criamos um Gist com comandos Git fictícios e seguros.

## 3. Resultado

A Wiki foi publicada, as configurações foram verificadas e o Gist foi criado com sucesso.

## 4. Aprendizados

Compreendemos como a Wiki complementa o README, como as configurações controlam recursos do repositório e como o Gist permite compartilhar exemplos de código.
