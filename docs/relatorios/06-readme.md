# Parte 6 — README em Markdown

## 1. Objetivo

Criar a documentação principal do DevStudy Hub para apresentar o projeto e facilitar sua utilização.

## 2. Procedimentos

Atualizamos o `README.md` com a descrição do projeto, funcionalidades, estrutura de diretórios, instruções de execução, fluxo Git, Issues e links para os relatórios.

Registramos as alterações em um commit e realizamos o merge pela Pull Request #10.

## 3. Resultado

O README foi integrado à branch `main`. O link do GitHub Pages será acrescentado após a publicação do site.

## 4. Aprendizados

Aprendemos a utilizar títulos, listas, tabelas, checklists, blocos de código e links internos para organizar a documentação em Markdown.
